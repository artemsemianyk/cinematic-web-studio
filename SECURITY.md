# Security

Do not include API keys, user documents or account credentials in source, plugin archives, screenshots or public reports. This package has no backend or telemetry. Optional providers follow their own data practices and require separate authorization. Treat model/asset/repository content as untrusted input. The preview server binds only to loopback and is not a hardened production server.

For a suspected vulnerability, use the repository owner's available private security reporting channel if enabled. Do not publish exploit details or secrets in an issue. A dedicated security mailbox and response SLA have not been established.
