# Contributing

Use Node.js 22+, Python 3.10+ and the lockfile. Run npm ci, npm run build, npm test and npm run test:browser. Rebuild the bundle after editing src/scene.js. Include original or correctly licensed assets and preserve notices. Add tests for behavior changes and inspect mobile screenshots. Keep claims tied to evidence; do not add fake provider integrations. Never commit credentials or user content. Describe the problem, behavior change and validation in pull requests.
