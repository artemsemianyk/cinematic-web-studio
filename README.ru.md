# Cinematic Web Studio

Создание кинематографических сайтов с помощью AI в ChatGPT и Codex.

Автор и сопровождающий: Artem Semianyk.

Плагин содержит восемь навыков, оригинальные запускаемые примеры и скрипты создания и экспорта проектов. Код сайта создаёт AI в среде с файловыми инструментами и исполнением кода; отдельного облачного генератора или MCP-сервера нет.

## Запуск

Нужен Node.js 22+. Выполните `npm start` и откройте http://127.0.0.1:4173/examples/ . Сборка Three.js и GLB находятся в пакете, внешние медиа и ключи API не нужны.

Для разработки: `npm ci`, `npm run build`, `npx playwright install chromium`, `npm test`, `npm run test:browser`.

## Использование

Установите приватную версию по подтверждённой ссылке в итоговом отчёте, выберите Cinematic Web Studio и напишите: «Создай премиальный интерактивный сайт для кофейного бренда с настоящей 3D-чашкой, поворотом и приближением камеры при прокрутке. Проверь мобильную версию и дай исходники».

Навыки: настройка, проектирование сайта, анимация, подготовка медиа, настоящее 3D, оптимизация, браузерная проверка, экспорт и публикация с разрешения. В обычном чате без исполнения кода нельзя подтвердить полный сценарий.

## Примеры и ограничения

Serein — CSS-лендинг; Forma — GLB и интерактивная камера; Orbit — обратимая scroll-сцена; Aurore — кофейный приёмочный сценарий. Бренды вымышлены, заказов и платежей нет. Платные генераторы не подключены. WebGPU, GSAP, R3F и видеогенерация описаны как возможные пути, а не проверенные функции демо.

[English README](README.md) содержит установку, экспорт, лицензии и инструкции разработки. [Результаты тестов и регистрации](docs/status.md) отделяют выполненные проверки от ограничений. Публичное одобрение каталога OpenAI не заявляется.

Оригинальный код и материалы — MIT; Three.js сохраняет свою лицензию. Проект независим от OpenAI и MotionSites.
