# Performance budgets and checks

Start with a 1 MB compressed initial-transfer target and a 5 MB media target for a simple landing page, adjusting only with a documented reason. These are project budgets, not measured scores. Inspect actual network transfer sizes before claiming compliance.

Keep text and navigation available without WebGL. Set media dimensions to prevent layout shifts. Lazy-load below-fold assets; do not defer the hero's essential content. Prefer local pinned dependencies, system fonts and simple effects. Bound image-sequence caches and video resolution.

For 3D cap DPR at 1.5 on small screens and 2 otherwise, draw on demand, stop hidden/offscreen work, and dispose GPU resources on teardown. Support missing-model and context failures. Reduced motion disables ambient steam and scroll camera/object motion, while explicit user controls remain available.

Measure LCP, CLS and INP with real browser tooling where available. No field Core Web Vitals, Lighthouse score, physical-phone performance or Safari result is claimed solely from Chromium functional tests.
