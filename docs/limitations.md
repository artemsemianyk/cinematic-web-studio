# Known limitations

- Requires host file/code/browser tools for full build-and-test behavior. Skills do not grant missing capabilities.
- No remote MCP server, hosted generation API, database, payments or automatic production deployment.
- Scaffold is template copying plus safe brand substitution; the host must customize source to fulfill a novel brief.
- Three runnable studies plus a coffee acceptance scenario do not establish every possible animation technology.
- GSAP, R3F, WebGPU, video generation, image sequences and shader/particle effects are conditional guidance, not bundled tested implementations.
- No paid media provider authorization or generated result is verified.
- Bundled cup is original stylized geometry, not a photoreal scan. Steam is CSS decoration. No embedded GLB animation clips.
- Chromium mobile emulation is not Safari, Firefox or real-phone testing. Field Core Web Vitals are unmeasured.
- Private creation is not installation, automatic skill activation, public submission or directory approval. See status.md for exact evidence.
- Example brand stories are fictional; no commercial order is placed.
